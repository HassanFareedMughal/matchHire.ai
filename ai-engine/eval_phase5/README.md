FYP‑II Phase 5 — Expanded Evaluation (Annotation-ready)
=====================================================

This folder contains a candidate dataset for Phase 5. To preserve rigor
and avoid fabricated ground-truth labels, the candidate pairs are left
unlabeled (`label: null`). A human annotator must assign labels before
running the evaluation.

Files:
- `dataset_candidates.json` — resumes, jobs, and `pairs_to_label` with `label:null`.
- `pairs_to_label.csv` — (generated by you or script) CSV view for annotators (not included automatically).
- `eval_phase5.py` — evaluation script (runs only when labeled pairs exist).

Label definitions (same as Phase 4):
- `0` — Not relevant
- `1` — Moderately relevant / some overlap
- `2` — Highly relevant / clear match

Binary mapping used by the evaluation script: label >= 1 → relevant (1), label == 0 → not relevant (0).

Annotation instructions:
1. Open `dataset_candidates.json` and export `pairs_to_label` to a CSV with columns: `resume_id`, `job_id`, `label`.
2. For each row, read the resume text and job description and assign one of {0,1,2} according to the definitions.
3. Save the annotated CSV and replace the `label` fields in `dataset_candidates.json` with the assigned integers.

Reproducible evaluation (after labeling):
```
& ".venv/Scripts/python.exe" "ai-engine/eval_phase5/eval_phase5.py"
```
